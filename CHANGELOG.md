# MasjidTime - Version History

MasjidTime is developed and maintained by **Cloud S/ntax**.

This changelog summarises the major milestones in the development of MasjidTime. Only selected stable releases are available for public download.

## v1.4.2 - 10 November 2026

**Windows and Linux**

### Improvements
- Corrected prayer highlighting to follow prayer entry times.
- Fajr highlighting now ends at sunrise.
- Removed prayer highlighting between sunrise and Dhuhr.
- Updated Iqamah highlighting to start 20 minutes before Iqamah and end 5 minutes afterwards.
- Added regression tests for prayer highlighting behaviour.

## v1.4.1 - November 2026

- Maintenance and stability release for Windows and Linux.
- Continued cross-platform testing and refinement.

## v1.4.0 - November 2026

- Cross-platform application improvements.
- Windows and Linux build and release workflow refinements.

## v1.3.5 - November 2026

- Linux compatibility and application support.
- Device-based licensing support for Linux.
- Cross-platform activation and release testing.

## v1.2.x - October 2026

- Introduced custom CSV prayer timetable support.
- Added configurable prayer entry and Iqamah times.
- Added Friday-only Jummah exception fields.
- Improved General Settings layout.
- Refined Hijri date settings and display controls.

## v1.0.0 - October 2026

- Initial Windows production release.
- Prayer timetable display functionality.
- Masjid configuration and display settings.
- Device-based application activation.
