# Installing MasjidTime on Linux

**MasjidTime v1.4.2 - Cloud S/ntax**

## 1. Download

Download the Linux release from:

[MasjidTime for Linux](https://github.com/Cloud-Syntax/MasjidTime-Downloads/releases/tag/v1.4.2.linux)

Download `MasjidTime_v1.4.2_Linux.zip`.

## 2. Extract the application

1. Open your Downloads folder.
2. Extract the ZIP archive.
3. Keep all extracted files and folders together.

Alternatively, extract using Terminal:

```bash
unzip MasjidTime_v1.4.2_Linux.zip
```

## 3. Launch MasjidTime

Open Terminal in the extracted application folder.

Make the application executable if required:

```bash
chmod +x MasjidTime
```

Launch the application:

```bash
./MasjidTime
```

MasjidTime has been tested on Zorin OS. Compatibility with other Linux distributions may vary.

## 4. Activate the application

MasjidTime uses device-based licensing.

If activation is required, follow the on-screen instructions to import a valid licence file supplied by Cloud S/ntax.

Licences are device-specific and may not transfer automatically between computers.

## 5. Configure your masjid

After launching:

1. Configure the masjid name and location.
2. Select the prayer calculation method or import a custom timetable.
3. Configure Iqamah and Jummah times.
4. Adjust Hijri date settings.
5. Configure themes, fonts and display preferences.
6. Save and verify the timetable.

## 6. Updating MasjidTime

1. Download the new Linux release.
2. Extract it into a separate directory.
3. Back up your existing configuration.
4. Launch and test the new version.
5. Keep the previous release until the new version is verified.

Avoid deleting your existing licence or application settings.

## Troubleshooting

If the application does not launch:

- Confirm the complete archive was extracted.
- Check executable permissions using `chmod +x MasjidTime`.
- Run from Terminal to view any error messages.
- Confirm that you downloaded the Linux package.
- Contact Cloud S/ntax if activation fails.
