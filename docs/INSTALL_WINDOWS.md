# Installing MasjidTime on Windows

**MasjidTime v1.4.2 - Cloud S/ntax**

## 1. Download

Download the latest Windows release from:

[MasjidTime for Windows](https://github.com/Cloud-Syntax/MasjidTime-Downloads/releases/tag/v1.4.2.win)

Download `MasjidTime_v1.4.2_Windows.zip`.

## 2. Extract the application

1. Right-click the downloaded ZIP file.
2. Select **Extract All**.
3. Choose a suitable installation folder.
4. Keep all extracted application files together.

MasjidTime is distributed as a portable application and does not require a traditional Windows installer.

## 3. Launch MasjidTime

Open the extracted folder and double-click `MasjidTime.exe`.

If Windows displays a security warning, verify that the file was downloaded from the official Cloud S/ntax GitHub repository before deciding whether to proceed.

## 4. Activate the application

MasjidTime uses device-based licensing.

If the application requests activation, follow the on-screen instructions to obtain and import a valid licence file supplied by Cloud S/ntax.

Keep your licence file secure.

## 5. Configure your masjid

After launching MasjidTime:

1. Open the application settings.
2. Configure your masjid details and location.
3. Select your prayer calculation method or import a custom timetable.
4. Configure Iqamah and Jummah times.
5. Adjust display settings, fonts and themes.
6. Save your settings and verify the displayed timetable.

## 6. Updating MasjidTime

When a newer release becomes available:

1. Download and extract the new version into a separate folder.
2. Back up your existing configuration.
3. Launch and test the new version before replacing your existing installation.
4. Retain the previous working version until the update is verified.

Avoid deleting existing settings or licence files.

## Troubleshooting

If MasjidTime does not start:

- Confirm the complete ZIP archive was extracted.
- Check that antivirus software has not quarantined the executable.
- Verify that the correct Windows package was downloaded.
- Contact Cloud S/ntax if activation fails.
