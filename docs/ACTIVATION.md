# MasjidTime - Licence Activation Guide

**Windows and Linux | Cloud S/ntax**

MasjidTime uses device-based software licensing. Each installation requires a valid licence issued by Cloud S/ntax.

## 1. Launch MasjidTime

Download, extract and launch the application using the appropriate installation guide:

- [Windows Installation Guide](INSTALL_WINDOWS.md)
- [Linux Installation Guide](INSTALL_LINUX.md)

If no valid licence is detected, MasjidTime displays its activation screen.

## 2. Locate your Device ID

The activation screen displays a unique **Device ID** associated with your computer.

This identifier allows Cloud S/ntax to issue a licence for your installation.

Copy the Device ID exactly as displayed.

## 3. Request a licence

Contact Cloud S/ntax and provide:

- Your Device ID
- Your masjid or organisation name
- Your contact details
- Your operating system (Windows or Linux)

Cloud S/ntax will use this information to prepare the appropriate licence.

**Important:** The Device ID is not a password. However, avoid sharing it publicly.

## 4. Receive your licence file

Once your request has been processed, Cloud S/ntax will provide a licence file with the `.lic` extension.

Keep this file secure.

Do not rename or modify its contents unless instructed by Cloud S/ntax.

## 5. Activate MasjidTime

1. Open MasjidTime.
2. Navigate to the activation screen if it is not already displayed.
3. Select the option to import a licence file.
4. Browse to the `.lic` file supplied by Cloud S/ntax.
5. Complete the import process.

MasjidTime will validate the licence against the device.

If activation succeeds, you can proceed to use the application.

## 6. Moving to another computer

MasjidTime licences are device-specific.

A licence issued for one computer may not work on another.

If you replace your computer, reinstall your operating system or make significant hardware changes, contact Cloud S/ntax for assistance.

## 7. Troubleshooting

### Licence not recognised

Confirm that you are importing the correct `.lic` file and that it was issued for your Device ID.

### Device ID has changed

Contact Cloud S/ntax with the new Device ID.

### Licence import fails

Ensure the file has not been modified or corrupted. Contact Cloud S/ntax if the problem persists.

### Application requests activation again

Contact Cloud S/ntax before deleting any existing licence or configuration files.
