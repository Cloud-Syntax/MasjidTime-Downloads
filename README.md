# MasjidTime

**Prayer Timetable Display Software for Masajid**

Developed by **Cloud S/ntax**

MasjidTime is a dedicated prayer timetable display application designed for masajid and Islamic centres. It provides a clear, customisable display of daily prayer times, Iqamah times and important announcements.

Available for Windows and Linux.

## Key Features

- Daily prayer entry and Iqamah times
- Automatic prayer highlighting
- Configurable Iqamah highlighting periods
- Multiple masjid configurations
- Custom prayer timetable imports using CSV
- Friday Jummah prayer schedules
- Hijri date display and adjustments
- Customisable themes, fonts and layouts
- Promotional and announcement content
- Windows and Linux support
- Device-based software licensing
